# MTPV – Multi-Tablet PDF Viewer

Shows one PDF on several Android tablets side by side, one page per screen, like extra monitors on a
PC. One tablet (the controller) opens the PDF and turns the pages; the others (secondaries) each
show the following page. Made for sheet music on a music stand. Handwritten notes with finger or
stylus, Bluetooth pedals and pairing included; Android 10+, no internet needed (a shared Wi-Fi or a
direct network between the tablets). On a single tablet it works as a plain sheet music reader with song sets, pedal and notes.

## Install

On each tablet (Android 10 or newer), either:

- **F-Droid** (with updates): follow the steps on [ernstkl.github.io/fdroid](https://ernstkl.github.io/fdroid/):
  install an F-Droid app, add the repository `https://ernstkl.github.io/fdroid/repo`, install MTPV.
- **APK**: download `mtpv-<version>.apk` from [Releases](https://github.com/ernstkl/mtpv/releases) and
  open it; allow the browser to install apps when Android asks.

Both are the same APK, signed by the developer, so one installs over the other and keeps the app's data.
